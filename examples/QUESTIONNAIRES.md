# Нейропсихологические опросники

Коллекция валидированных нейропсихологических опросников для скрининга и первичной оценки детей.

## ⚠️ Важные дисклеймеры

1. **Эти опросники предназначены ТОЛЬКО для скрининга** - они не заменяют полноценную диагностику
2. **Результаты должны интерпретироваться специалистом** - автоматическая интерпретация является предварительной
3. **Это НЕ диагностические инструменты** - окончательный диагноз может поставить только квалифицированный специалист
4. **Опросники адаптированы** для формата Telegram-бота и могут отличаться от оригинальных версий

## Доступные опросники

### 1. M-CHAT-R - Модифицированный скрининг аутизма

**Файлы:** `mchat-questionnaire.json`, `mchat-scoring.json`

**Возраст:** 16-30 месяцев
**Вопросов:** 20
**Время прохождения:** 5-7 минут

**Назначение:**
Раннее выявление признаков расстройств аутистического спектра (РАС) у детей раннего возраста.

**Оценивает:**
- Социальное взаимодействие
- Коммуникативные навыки
- Повторяющееся поведение
- Сенсорные особенности

**Интерпретация:**
- **0-2 балла:** Низкий риск РАС
- **3-7 баллов:** Средний риск - рекомендуется повторная оценка через 3 месяца
- **8+ баллов:** Высокий риск - требуется углубленная диагностика

**Когда использовать:**
- Плановые осмотры детей 18-24 месяцев
- При наличии опасений у родителей
- Задержка речевого развития
- Особенности социального взаимодействия

**Как загрузить:**
```bash
curl -X POST http://localhost:8088/questionnaires \
  -H "Content-Type: application/json" \
  -d "{
    \"questionnaire\": $(cat mchat-questionnaire.json),
    \"scoring\": $(cat mchat-scoring.json)
  }"
```

### 2. SDQ - Опросник сильных сторон и трудностей

**Файлы:** `sdq-questionnaire.json`, `sdq-scoring.json`

**Возраст:** 4-17 лет
**Вопросов:** 25
**Время прохождения:** 5-10 минут

**Назначение:**
Скрининг эмоциональных и поведенческих проблем у детей и подростков.

**Оценивает 5 шкал:**
1. **Эмоциональные симптомы** - тревожность, страхи, депрессивность
2. **Проблемы поведения** - агрессия, непослушание, конфликтность
3. **Гиперактивность/невнимательность** - СДВГ-симптомы
4. **Проблемы со сверстниками** - социальные трудности
5. **Просоциальное поведение** - помощь другим, эмпатия

**Интерпретация (общий балл трудностей):**
- **0-13:** Норма
- **14-16:** Пограничный уровень
- **17-40:** Клинически значимый уровень

**Когда использовать:**
- Общий скрининг психического здоровья
- Проблемы поведения в школе/дома
- Эмоциональные трудности
- Мониторинг эффективности терапии

**Преимущества:**
- Быстрый и простой
- Хорошо валидирован международно
- Используется в исследованиях

### 3. Скрининг СДВГ

**Файлы:** `adhd-questionnaire.json`, `adhd-scoring.json`

**Возраст:** 6-17 лет
**Вопросов:** 18 + дополнительные
**Время прохождения:** 8-12 минут

**Назначение:**
Скрининг синдрома дефицита внимания и гиперактивности (СДВГ).

**Оценивает 2 шкалы:**
1. **Невнимательность** (9 симптомов)
   - Трудности концентрации
   - Забывчивость
   - Неорганизованность

2. **Гиперактивность/Импульсивность** (9 симптомов)
   - Чрезмерная активность
   - Нетерпеливость
   - Импульсивность

**Критерии (согласно DSM-5):**
- 6+ симптомов невнимательности (часто/очень часто)
- 6+ симптомов гиперактивности (часто/очень часто)
- Симптомы > 6 месяцев
- Проявляются в 2+ ситуациях (дом, школа, др.)

**Интерпретация:**
- **0-5 баллов:** Низкий риск
- **6-11 баллов:** Умеренный риск - требуется наблюдение
- **12+ баллов:** Высокий риск - рекомендуется диагностика

**Когда использовать:**
- Проблемы с учебой
- Неусидчивость, импульсивность
- Трудности выполнения заданий
- Дезорганизация

**Важно:**
- Учитывать возрастные нормы активности
- Оценивать влияние на функционирование
- Исключить другие причины (тревожность, депрессия, проблемы со сном)

### 4. Краткий опросник сенсорной чувствительности

**Файлы:** `sensory-questionnaire.json`, `sensory-scoring.json`

**Возраст:** 3-17 лет
**Вопросов:** 15 + дополнительные
**Время прохождения:** 7-10 минут

**Назначение:**
Выявление особенностей сенсорной обработки информации.

**Оценивает 3 паттерна:**

1. **Гиперчувствительность (избегание)**
   - Чрезмерная реакция на стимулы
   - Избегание звуков, прикосновений, запахов
   - Дискомфорт от обычных ощущений

2. **Гипочувствительность (сниженная реакция)**
   - Недостаточная реакция на боль, температуру
   - Не замечает стимулы
   - Высокий порог чувствительности

3. **Сенсорный поиск**
   - Постоянная потребность в движении
   - Грубая игра
   - Жевание несъедобного
   - Любовь к интенсивным ощущениям

**Интерпретация:**
- **0-2 балла:** Типичная сенсорная обработка
- **3-5 баллов:** Умеренные особенности - консультация эрготерапевта
- **6+ баллов:** Выраженные особенности - рекомендуется сенсорная интеграционная терапия

**Когда использовать:**
- Необычные реакции на звуки, прикосновения
- Избирательность в еде
- Проблемы с координацией
- Необычное поведение (верчение, жевание)
- При подозрении на аутизм или СДВГ

**Что дальше:**
При выраженных сенсорных особенностях рекомендуется консультация эрготерапевта для разработки программы сенсорной интеграции.

## Рекомендации по использованию

### Выбор опросника

| Возраст | Основная проблема | Рекомендуемый опросник |
|---------|-------------------|------------------------|
| 16-30 мес | Подозрение на аутизм | M-CHAT-R |
| 4-17 лет | Общий скрининг | SDQ |
| 6-17 лет | Невнимательность, гиперактивность | СДВГ |
| 3-17 лет | Сенсорные особенности | Сенсорный опросник |

### Комбинирование опросников

Для комплексной оценки можно использовать несколько опросников:

**При подозрении на аутизм:**
- M-CHAT-R (для малышей) или SDQ
- + Сенсорный опросник

**При проблемах в школе:**
- СДВГ
- + SDQ
- + Сенсорный опросник (если есть особенности)

**Эмоциональные проблемы:**
- SDQ (основной)
- + СДВГ (если есть невнимательность)

### Загрузка всех опросников

```bash
#!/bin/bash

# M-CHAT-R
curl -X POST http://localhost:8088/questionnaires \
  -H "Content-Type: application/json" \
  -d "{\"questionnaire\": $(cat mchat-questionnaire.json), \"scoring\": $(cat mchat-scoring.json)}"

# SDQ
curl -X POST http://localhost:8088/questionnaires \
  -H "Content-Type: application/json" \
  -d "{\"questionnaire\": $(cat sdq-questionnaire.json), \"scoring\": $(cat sdq-scoring.json)}"

# ADHD
curl -X POST http://localhost:8088/questionnaires \
  -H "Content-Type: application/json" \
  -d "{\"questionnaire\": $(cat adhd-questionnaire.json), \"scoring\": $(cat adhd-scoring.json)}"

# Sensory
curl -X POST http://localhost:8088/questionnaires \
  -H "Content-Type: application/json" \
  -d "{\"questionnaire\": $(cat sensory-questionnaire.json), \"scoring\": $(cat sensory-scoring.json)}"
```

## Интерпретация результатов

### ⚠️ Важно

1. **Результаты - это только скрининг**, не диагноз
2. **Учитывайте контекст:** возраст, культуру, ситуацию в семье
3. **Один высокий балл** не означает наличие расстройства
4. **Динамика важна:** одна точка оценки недостаточна
5. **Обращайтесь к специалистам** при любых сомнениях

### Когда направлять к специалистам

**Срочно (в течение недели):**
- Мысли о самоповреждении/суициде
- Выраженная агрессия
- Полная социальная изоляция
- Регресс навыков

**В ближайшее время (1-2 недели):**
- Высокий риск по опросникам
- Значительное влияние на функционирование
- Опасения родителей/педагогов

**Плановая консультация (1-3 месяца):**
- Пограничные результаты
- Умеренные трудности
- Профилактическая оценка

## К каким специалистам обращаться

**Детский психиатр:**
- СДВГ
- Тревожность, депрессия
- РАС (диагностика)
- Поведенческие проблемы

**Нейропсихолог:**
- Оценка когнитивных функций
- Трудности обучения
- Проблемы памяти, внимания
- Комплексная диагностика РАС

**Детский психолог:**
- Эмоциональные проблемы
- Проблемы поведения
- Детско-родительские отношения
- Психотерапия

**Эрготерапевт:**
- Сенсорные особенности
- Проблемы моторики
- Самообслуживание
- Сенсорная интеграция

**Логопед-дефектолог:**
- Задержка речи
- Коммуникативные трудности
- Социальные навыки
