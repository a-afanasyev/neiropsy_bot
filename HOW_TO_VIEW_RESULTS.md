# 📊 Как просмотреть результаты в Telegram боте

## Для администратора

### Способ 1: Автоматическое уведомление

Когда клиент завершает прохождение батча, администратор **автоматически получает уведомление** с кнопками:

1. **📄 Посмотреть отчет** - показывает текстовый отчет с результатами
2. **💾 Выгрузить JSON** - скачивает отчет в формате JSON
3. **📊 Выгрузить CSV** - скачивает отчет в формате CSV

**Просто нажмите на кнопку "Посмотреть отчет"** в уведомлении.

---

### Способ 2: Через главное меню (если реализовано)

1. Отправьте команду `/start` боту
2. В главном меню нажмите **"📊 Мои батчи"**
3. Выберите нужный батч из списка
4. Просмотрите результаты

---

## Текущая реализация

### ✅ Реализовано:
- Автоматическое уведомление администратора при завершении батча
- Кнопка "Посмотреть отчет" - показывает текстовый отчет
- Кнопки экспорта (JSON/CSV) - **требуют реализации обработчиков**

### ⚠️ Требует реализации:
- Обработчики для кнопок экспорта (`admin_export_json_`, `admin_export_csv_`)
- Функция просмотра списка батчей (`admin_view_batches`)
- Возможность просмотреть отчеты старых батчей

---

## Альтернативный способ: через REST API

Если нужно просмотреть результаты программно или через браузер:

```bash
# Получить отчет по session_id
curl http://localhost:8088/batch-reports/{batch_session_id}

# Экспорт в JSON
curl http://localhost:8088/exports/batch-report/{batch_session_id}.json

# Экспорт в CSV
curl http://localhost:8088/exports/batch-report/{batch_session_id}.csv
```

---

## Пример работы

1. **Клиент проходит батч** → завершает все опросники
2. **Администратор получает уведомление:**
   ```
   📊 Клиент завершил батч опросников!
   
   📅 Дата: 07.11.2025 13:44
   📝 Опросников: 2
   ⏱ Время прохождения: 15 минут
   
   [📄 Посмотреть отчет]
   [💾 Выгрузить JSON] [📊 Выгрузить CSV]
   ```
3. **Нажимает "Посмотреть отчет"** → получает текстовый отчет с результатами

---

## Что показывает отчет

Отчет содержит:
- Сводную информацию по каждому опроснику
- Общие баллы (overall_score)
- Баллы по шкалам (если есть)
- Флаги/риски (если настроены)
- Текстовую интерпретацию результатов

---

## Примечание

Если кнопки экспорта не работают, это нормально - обработчики еще не реализованы. 
Но просмотр отчета через кнопку "Посмотреть отчет" работает!
