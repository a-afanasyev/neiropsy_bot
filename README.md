# Neiropsy Bot

Telegram-бот и REST API для проведения батчевых психологических опросов.

## 🎯 Описание

Монолитный сервис на Node.js/TypeScript для проведения психологических опросов через Telegram с возможностью объединения нескольких опросников в батчи. Система автоматически агрегирует результаты и формирует сводные отчеты.

## ✨ Основные возможности

- 📋 **Батчевые опросы**: объединение 2-10 опросников в один сеанс
- 🤖 **Telegram бот**: полностью кнопочный интерфейс на русском языке
- 🌐 **REST API**: управление батчами и получение отчетов
- 📊 **Автоматическая агрегация**: расчет баллов и генерация отчетов
- 💾 **Экспорт данных**: JSON и CSV форматы
- 🔄 **FSM логика**: отслеживание прогресса прохождения
- 💡 **Сохранение прогресса**: возможность делать перерывы

## 📋 Требования

- Node.js >= 18.0.0
- PostgreSQL >= 12
- Redis >= 6 (опционально, рекомендуется)
- Docker и Docker Compose (для запуска через контейнеры)

## 🚀 Быстрый старт

### Через Docker Compose (рекомендуется)

1. Клонируйте репозиторий
2. Создайте файл `.env` (см. `.env.example`)
3. Запустите:

```bash
docker-compose up -d
```

### Локальная разработка

1. Установите зависимости:

```bash
npm install
```

2. Настройте `.env` файл:

```bash
cp .env.example .env
# Отредактируйте .env, укажите токен бота и другие параметры
```

3. Запустите PostgreSQL и Redis (локально или через Docker)

4. Выполните миграции:

```bash
npm run migrate
```

5. Запустите в режиме разработки:

```bash
npm run dev
```

## ⚙️ Конфигурация

Все настройки задаются через переменные окружения в файле `.env`:

| Переменная | Описание | Обязательна |
|------------|----------|-------------|
| `TELEGRAM_BOT_TOKEN` | Токен бота от @BotFather | Да |
| `ADMIN_TELEGRAM_ID` | Telegram ID администратора | Да |
| `DATABASE_URL` | URL подключения к PostgreSQL | Да |
| `REDIS_URL` | URL подключения к Redis | Нет |
| `PORT` | Порт для REST API (по умолчанию 8088) | Нет |
| `NODE_ENV` | Окружение (development/production) | Нет |
| `LOG_LEVEL` | Уровень логирования (debug/info/warn/error) | Нет |

## 🔌 API Endpoints

### Батчи

- `POST /batches` - Создать батч
- `GET /batches/:batch_id` - Получить информацию о батче

### Сессии

- `POST /batch-sessions` - Создать сессию (генерация ссылки)
- `GET /batch-sessions/:token` - Проверить статус сессии

### Отчеты

- `GET /batch-reports/:batch_session_id` - Получить отчет
- `GET /exports/batch-report/:batch_session_id.json` - Экспорт в JSON
- `GET /exports/batch-report/:batch_session_id.csv` - Экспорт в CSV

### Опросники

- `POST /questionnaires` - Загрузить опросник (требуется Telegram ID администратора)
