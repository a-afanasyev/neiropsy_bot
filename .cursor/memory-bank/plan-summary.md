**Дата**: 2025-11-06

## 📋 ЧТО ЗАПЛАНИРОВАНО

Разработка системы **батч-опросников** - возможность создавать наборы из нескольких опросников, которые пользователь проходит последовательно по одной ссылке.

---

## 🎯 ОСНОВНЫЕ ВОЗМОЖНОСТИ

### Для специалиста:
1. ✅ Команда `/newbatch` - создание батча из нескольких опросников
2. ✅ Выбор опросников через интерактивное меню (чекбоксы)
3. ✅ Генерация одной ссылки на весь батч
4. ✅ Получение агрегированного отчета после завершения
5. ✅ Выгрузка детальных данных (JSON, CSV)

### Для пользователя:
1. ✅ Переход по одной ссылке
2. ✅ Последовательное прохождение всех опросников
3. ✅ Индикация прогресса ("Опросник 2 из 4")
4. ✅ Автоматический переход между опросниками
5. ✅ Сохранение прогресса

---

## 🏗️ ТЕХНИЧЕСКАЯ РЕАЛИЗАЦИЯ

### Новые таблицы БД (5 штук):
1. **questionnaire_batches** - сами батчи
2. **batch_questionnaires** - связь батчей с опросниками + порядок
3. **batch_sessions** - сессии для батчей (токены)
4. **batch_responses** - связь ответов с батчами
5. **batch_reports** - агрегированные отчеты

### Новый код:
- **Миграция БД**: `006_add_batch_questionnaires.sql`
- **Типы**: новые интерфейсы в `types.ts`
- **Репозиторий**: ~12 новых методов в `repo.ts`
- **API**: 6 новых endpoints в `server.ts`
- **Бот**: 4 новых команды/обработчика в `bot.ts`
- **Scoring**: функция агрегирования в `scoring.ts`
