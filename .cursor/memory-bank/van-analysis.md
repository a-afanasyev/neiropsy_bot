### 3️⃣ Анализ требований

#### Функциональные требования (из ТЗ)
1. **Telegram бот**
   - Русскоязычный интерфейс
   - Только кнопки (без текстовых команд)
   - Для администратора: создание батчей
   - Для клиентов: прохождение опросов
   - Уведомления о завершении

2. **REST API**
   - Создание батчей (`POST /batches`)
   - Генерация сессий (`POST /batch-sessions`)
   - Получение отчетов (`GET /batch-reports/:id`)
   - Экспорт JSON/CSV (`GET /exports/...`)
   - Загрузка опросников (`POST /questionnaires`)

3. **Бизнес-логика**
   - FSM для управления состоянием сессий
   - Последовательное проведение 2-10 опросников
   - Автоматическая агрегация результатов
   - Генерация отчетов

4. **База данных**
   - `questionnaires` - шаблоны опросников
   - `questionnaire_batches` - батчи
   - `batch_questionnaires` - состав батчей
   - `batch_sessions` - сессии прохождения
   - `batch_responses` - связи ответов
   - `batch_reports` - агрегированные отчеты
   - `responses` - индивидуальные результаты

#### Нефункциональные требования
- **Производительность**: <100ms API, <500ms генерация отчета
- **Надежность**: Транзакционность, обработка ошибок
- **Безопасность**: Проверка Telegram ID администратора
- **Масштабируемость**: Поддержка 5-10 параллельных сессий
- **Поддерживаемость**: TypeScript, модульная структура
