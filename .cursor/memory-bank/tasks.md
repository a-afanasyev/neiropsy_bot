**Дата**: 2025-11-06

## 📝 Техническое задание
Монолитный сервис на Node.js (TypeScript), который объединяет:
- Telegram-бот для проведения психологических опросов
- REST API для управления батчами опросников
- Батчевая система: специалист создает набор из 2-10 опросников, клиент проходит их последовательно
- Автоматическая агрегация результатов и генерация отчетов

## 🏗️ Архитектура
- **Платформа**: Node.js + TypeScript
- **База данных**: PostgreSQL
- **State Storage**: Redis (опционально, in-memory для MVP)
- **Деплой**: Docker Compose
- **Компоненты**:
  - TelegramController (бот)
  - RestController (API)
  - BatchService (бизнес-логика)
  - Database (PostgreSQL)
