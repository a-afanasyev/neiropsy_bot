## 🎯 ЦЕЛЬ ФИЧИ

Дать специалисту возможность отправить клиенту **несколько опросников последовательно** по одной ссылке.

### Что нужно:
- ✅ Специалист создает группу из 2-10 опросников
- ✅ Генерируется одна ссылка
- ✅ Клиент проходит опросники друг за другом
- ✅ Специалист видит все результаты

### Что НЕ нужно:
- ❌ Сложная система "батчей" как отдельных сущностей
- ❌ Агрегированные отчеты (можно просто список ответов)
- ❌ Множество новых таблиц
- ❌ Специальные API для аналитики

## 🏗️ АРХИТЕКТУРА (Упрощенная)

### Основная идея

**Добавить 3 поля в существующую таблицу `sessions`:**

```sql
questionnaire_ids JSONB           -- Массив UUID опросников
current_questionnaire_index INT   -- Индекс текущего (0-based)
total_questionnaires INT          -- Общее количество
```

**Логика:**
1. Если `questionnaire_ids` = NULL → одиночный опросник (как сейчас)
2. Если `questionnaire_ids` != NULL → группа опросников

**Совместимость:**
- ✅ Существующие сессии продолжают работать (NULL = одиночный)
- ✅ Код для одиночных опросников не меняется
- ✅ Добавляется только логика для групп

## 🗄️ СХЕМА БАЗЫ ДАННЫХ

### Изменения в таблице `sessions`

```sql
-- ДО (существующая структура):
CREATE TABLE sessions (
    id UUID PRIMARY KEY,
    questionnaire_id UUID NOT NULL,  -- Один опросник
    token VARCHAR(100) UNIQUE NOT NULL,
    expires_at TIMESTAMP,
    used BOOLEAN DEFAULT false,
    created_at TIMESTAMP,
    used_at TIMESTAMP
);

-- ПОСЛЕ (добавить 3 поля):
ALTER TABLE sessions ADD COLUMN
    questionnaire_ids JSONB,              -- Массив опросников
    current_questionnaire_index INT DEFAULT 0,
    total_questionnaires INT DEFAULT 1;
```

### Изменения в таблице `responses`

```sql
-- Добавить для отслеживания порядка
ALTER TABLE responses ADD COLUMN
    questionnaire_index INT DEFAULT NULL;
```

### View для мониторинга

```sql
CREATE VIEW multi_questionnaire_sessions AS
SELECT
    s.id,
    s.token,
    s.questionnaire_ids,
    s.current_questionnaire_index,
    s.total_questionnaires,
    COUNT(r.id) as completed_count
FROM sessions s
LEFT JOIN responses r ON r.session_id = s.id
WHERE s.questionnaire_ids IS NOT NULL
GROUP BY s.id;
```

**Итого миграция**: ~30 строк SQL ✅
