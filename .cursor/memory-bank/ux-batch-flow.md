# UX FLOW: Telegram бот для батч-опросников

**Дата**: 2025-11-06  
**Платформа**: Telegram Bot

---

## 🎯 ОБЩИЕ ПРИНЦИПЫ UX

### Язык и тон
- **Русский язык**: все сообщения
- **Дружелюбный тон**: поддерживающий, мотивирующий
- **Ясность**: короткие предложения, простые слова
- **Эмодзи**: для визуального разделения и эмоционального контакта

### Обратная связь
- **Немедленная**: реакция на каждое действие
- **Прогресс**: показывать текущее состояние
- **Мотивация**: похвала за промежуточные результаты
- **Помощь**: подсказки при возможных затруднениях

## 📱 СЦЕНАРИЙ 1: Создание батча (Специалист)

### Шаг 1: Команда `/newbatch`

**Входные данные**: Команда от специалиста  
**Проверка**: Пользователь является админом (config.admin_tg_id)

**Сообщение**:

```
📋 СОЗДАНИЕ БАТЧА ОПРОСНИКОВ

Выберите опросники, которые клиент пройдет последовательно.
Можно выбрать от 2 до 10 опросников.

Доступные опросники:

[Выбрать опросники]
```

**Inline Keyboard (callback_query)**:

Кнопка открывает список опросников с чекбоксами.

---

### Шаг 2: Выбор опросников

**Inline Keyboard**:

```
[ ] СДВГ скрининг (22 вопроса)
[ ] M-CHAT аутизм (22 вопроса)  
[ ] SDQ трудности (27 вопросов)
[ ] Сенсорная чувствительность (18 вопросов)
[ ] Демо опросник (6 вопросов)

Выбрано: 0 из 10

[✅ Создать батч]  [❌ Отмена]
```

**При клике на опросник**: чекбокс меняется на ✅

```
[✅] СДВГ скрининг (22 вопроса)
[✅] M-CHAT аутизм (22 вопроса)  
[✅] SDQ трудности (27 вопросов)
[ ] Сенсорная чувствительность (18 вопросов)
[ ] Демо опросник (6 вопросов)

Выбрано: 3 из 10
Всего вопросов: 71

[✅ Создать батч]  [❌ Отмена]
```

**Callback Data**: `batch_toggle_{questionnaire_id}`

---

### Шаг 3: Подтверждение создания

**При нажатии "Создать батч"**:

**Проверка**: Выбрано минимум 2 опросника

**Сообщение**:

```
⏳ Создаю батч...
```

**Затем (после создания)**:

```
✅ БАТЧ СОЗДАН!

📋 Название: "Комплексный скрининг"
🔢 Опросников: 3
❓ Всего вопросов: 71
⏰ Действителен до: 08.11.2025 15:30

Опросники в батче:
1️⃣ СДВГ скрининг (22 вопроса)
2️⃣ M-CHAT аутизм (22 вопроса)
3️⃣ SDQ трудности (27 вопросов)

🔗 Ссылка для клиента:
https://t.me/neiropsy_bot?start=batch_abc123xyz

Отправьте эту ссылку клиенту.
Примерное время прохождения: 15-20 минут.

[📋 Мои батчи] [➕ Создать еще]
```

**Callback Data**:
- `my_batches` - список батчей специалиста
- `new_batch` - создать новый батч

---

### Шаг 4: Если выбрано меньше 2 опросников

**Сообщение**:

```
⚠️ Необходимо выбрать минимум 2 опросника

Выбрано: 1

Пожалуйста, добавьте еще минимум 1 опросник.

[◀️ Назад к выбору]
```

## 📱 СЦЕНАРИЙ 2: Прохождение батча (Пользователь)

### Шаг 1: Переход по ссылке

**Команда**: `/start batch_abc123xyz`

**Проверка**:
- Токен существует
- Токен не истек
- Батч не завершен

**Сообщение**:

```
👋 Добро пожаловать!

Вам предстоит пройти 3 опросника:

1️⃣ СДВГ скрининг (22 вопроса)
2️⃣ M-CHAT аутизм (22 вопроса)
3️⃣ SDQ трудности (27 вопросов)

❓ Всего вопросов: 71
⏱ Примерное время: 15-20 минут

ℹ️ Вы можете делать перерывы - ваш прогресс сохраняется автоматически.

Готовы начать?

[▶️ Начать] [❓ Подробнее]
```

**Inline Keyboard**:
- `start_batch` - начать прохождение
- `batch_info` - дополнительная информация

---

### Шаг 2: Начало первого опросника

**При нажатии "Начать"**:

```
📝 ОПРОСНИК 1 из 3
🔹 СДВГ скрининг

Этот опросник помогает выявить признаки синдрома дефицита внимания и гиперактивности.

[▶️ Начать первый опросник]
```

**После нажатия**:

```
📝 Опросник 1 из 3: СДВГ скрининг
━━━━━━━━━━━━━━━━━━━━━━━━
Вопрос 1 из 22

Как часто ребенок отвлекается на внешние раздражители во время выполнения заданий?
```

**Inline Keyboard** (в зависимости от типа вопроса):

```
[0 - Никогда]
[1 - Редко]
[2 - Иногда]
[3 - Часто]
[4 - Очень часто]
```

---

### Шаг 3: Прогресс внутри опросника

**После каждого ответа**:

```
✅ Ответ сохранен

📝 Опросник 1 из 3: СДВГ скрининг
━━━━━━━━━━━━━━━━━━━━━━━━
Вопрос 5 из 22

[████████░░░░░░░░░░░░] 23%

Трудно ли ребенку сохранять внимание при выполнении домашних заданий?
```

**Прогресс-бар**: показывает прогресс внутри текущего опросника

---

### Шаг 4: Завершение первого опросника

**После последнего вопроса**:

```
🎉 ОПРОСНИК 1 ЗАВЕРШЕН!

✅ СДВГ скрининг - 22 вопроса пройдено

━━━━━━━━━━━━━━━━━━━━━━━━
Общий прогресс: [████████░░░░] 33%
━━━━━━━━━━━━━━━━━━━━━━━━

Следующий опросник:
📝 M-CHAT аутизм (22 вопроса)

[▶️ Продолжить]  [⏸ Сделать перерыв]
```

**Callback Data**:
- `continue_batch` - продолжить к следующему опроснику
- `pause_batch` - сохранить и выйти

---

### Шаг 5: Переход ко второму опроснику

**При нажатии "Продолжить"**:

```
📝 ОПРОСНИК 2 из 3
🔹 M-CHAT аутизм

[▶️ Начать второй опросник]
```

**Затем вопросы второго опросника...**

## 📱 СЦЕНАРИЙ 3: Получение отчета (Специалист)

### Вариант A: Автоматическое уведомление

**Когда пользователь завершает батч**:

```
📊 БАТЧ ЗАВЕРШЕН!

Клиент прошел все опросники:
✅ СДВГ скрининг
✅ M-CHAT аутизм
✅ SDQ трудности

⏱ Время прохождения: 18 минут
📅 Завершено: 06.11.2025 16:45

[📊 Посмотреть отчет]
```

**Callback Data**: `view_report_{batch_session_id}`

---

### Вариант B: Команда `/batchreport`

**Команда**: `/batchreport` (без параметров)

**Сообщение**:

```
📊 ЗАВЕРШЕННЫЕ БАТЧИ

Выберите батч для просмотра отчета:

[📋 Комплексный скрининг - завершен 06.11 16:45]
[📋 СДВГ + Sensory - завершен 05.11 14:20]
[📋 Полное обследование - завершен 04.11 10:15]

[◀️ Назад]
```

---

### Шаг 2: Просмотр отчета

- `back` - назад к списку

## ⚠️ СЦЕНАРИИ ОШИБОК

### Ошибка 1: Токен истек

**При попытке начать батч с истекшим токеном**:

```
⏰ СРОК ДЕЙСТВИЯ ССЫЛКИ ИСТЕК

Эта ссылка была действительна до 06.11.2025 15:30.

Пожалуйста, свяжитесь со специалистом для получения новой ссылки.

[❌ Закрыть]
```

---

### Ошибка 2: Батч уже завершен

**При попытке начать уже завершенный батч**:

```
✅ ВЫ УЖЕ ЗАВЕРШИЛИ ЭТИ ОПРОСНИКИ

Все опросники в этом батче уже пройдены.

Дата завершения: 06.11.2025 16:45

Если нужно пройти заново, попросите специалиста создать новую ссылку.

[❌ Закрыть]
```

---

### Ошибка 3: Не админ пытается создать батч

**При попытке не-админа использовать `/newbatch`**:

```
🔒 ДОСТУП ОГРАНИЧЕН

Эта команда доступна только специалистам.

Если вы получили ссылку для прохождения опросников, просто перейдите по ней.

[❓ Помощь]
```
